[ ] Use `jobs` as main engine structure.
[ ] The process hierarchy is the scene graph including transformations.
[ ] Everything is palettized.
	[ ] All palettes are limited to 256 16-bit colors
[ ] Split engine into; core, 2d, 2.5d, 3d.
	[ ] 2d rendering
		[ ] Sprite rendering
			[ ] Direct blit (1:1) with flipped axis rendering
			[ ] Stretchy blit
		[ ] Tile map
		[ ] VBLANK effects (let user run code when an entire horizontal line has been rendered)
	[ ] 3d rendering
		[ ] No depth buffer (only stencil buffer).
		[ ] Layer rendering; each layer will render in order.
		[ ] Portal rendering for level structures.
		[ ] All meshes must be BSP trees.
		[ ] Light maps for levels.
	[ ] 2.5d rendering
		[ ] ray casting
		[ ] ray surfing
	[ ] All modes must be able to be accessed through layers (you can render a 2d layer on top of a 3d game, and vice versa).
